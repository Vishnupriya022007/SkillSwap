# SkillSwap – Student Skill Exchange Platform

## About the Project

SkillSwap is a Java-based Student Skill Exchange Platform that allows students to share their knowledge and learn new skills from one another.

Students can offer skills they are proficient in and request to learn skills offered by other students. The platform helps create a collaborative learning environment through skill exchange.

## Features

- Student Management – Register and manage student details.
- Skill Management – Add and manage available skills.
- Skill Search – Find students who can teach a particular skill.
- Learning Requests – Send, accept or reject learning requests.
- Session Scheduling – Schedule learning sessions between students.
- Feedback Management – Submit ratings and feedback after completed sessions.

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- MySQL
- JDBC (Java Database Connectivity)

## Database Design

The project uses MySQL to store and manage:

- Student details
- Available skills
- Student skill mappings
- Learning requests
- Learning sessions
- Feedback and ratings

## OOP Concepts Used

- Classes and Objects
- Encapsulation
- Inheritance (where applicable)
- Polymorphism
- Abstraction

## Project Objective

To develop a platform where students can exchange skills, collaborate with each other and learn new technologies without depending entirely on traditional learning methods.
